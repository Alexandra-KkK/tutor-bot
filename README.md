# Бот для репетитора

Telegram-бот, в котором репетитор ведёт расписание, учеников и доход, а ученики и родители
сами получают расписание на неделю, напоминания перед уроком и сообщение «урок проведён».

## Что умеет

**Преподаватель** (главное меню):

| Кнопка | Что внутри |
|---|---|
| 📅 Расписание | Просмотр по дням, на неделю, на любую дату. Изменить всё расписание одним сообщением, добавить регулярное или разовое занятие, отменить или перенести урок (ученик и родители получают уведомление), удалить одно занятие или всё расписание. |
| 👥 Ученики | Список, карточка ученика: цена, заметка, занятия, кто подключён к боту, долг или предоплата. Личная ссылка-приглашение для ученика и родителей. Отправка домашнего задания (текст, фото, файл). Отчёт об уроке для родителей. |
| 💰 Доход | Сколько заработано за неделю и месяц, прогноз, оплаты от учеников, история оплат, долги. |
| ⭐ Моя подписка | Пробный период 15 дней, затем 299 ₽/мес. |
| Отменить подписку | Выключает автопродление, доступ сохраняется до конца оплаченного срока. |
| 🔑 Мои секреты | Секрет для входа с другого аккаунта, секрет и ссылка-приглашение для учеников и родителей. |
| ⚙️ Настройки | Часовой пояс, утренний план на день, за сколько напоминать ученикам, день и время еженедельной рассылки, ссылка на Google Диск, отчёты родителям, мемы. |
| 💬 Обратиться в поддержку | Сообщение уходит администратору бота, ответ приходит в чат. |
| ✖️ Отмена / 🔄 Рестарт профиля | Отменить текущее действие / удалить профиль и начать заново. |

**Ученик и родитель** подключаются по ссылке-приглашению. Удобнее всего личная ссылка из карточки ученика:
по ней бот сразу узнаёт, чей это ученик. По общей ссылке человек пишет имя, и бот находит ученика сам
(чужие имена никому не показываются). Если бот ошибся, преподаватель нажимает «Это другой ученик» в уведомлении.
Родитель может подключить нескольких детей: достаточно открыть личную ссылку каждого.

Ученику и родителю доступны: «Моё расписание», «Ближайшее занятие», «Мой преподаватель» (написать преподавателю прямо в боте).

**Автоматически бот:**
- раз в неделю (по умолчанию в воскресенье в 18:00) присылает каждому ученику и родителю расписание на 7 дней и ссылку на ваше расписание в Google Диске;
- перед уроком напоминает ученику (по умолчанию за час), с весёлой фразой и случайным мемом из вашей коллекции; если сам ученик не подключён, напоминание получает родитель;
- после урока сообщает родителям, что урок проведён (отменённые уроки не считаются);
- после урока предлагает преподавателю оставить родителям короткий отчёт: оценки от 1 до 5
  (старательность, продуктивность, понимание темы) и пару слов о том, что делали. Это по желанию:
  можно нажать «Не нужно» или выключить в настройках. Ученик оценки не видит;
- если новое занятие пересекается по времени с другим, предупреждает;
- в 8:00 присылает преподавателю план на день;
- предупреждает о конце пробного периода и подписки.

**Мемы.** «⚙️ Настройки» → «🖼 Мемы для учеников», затем просто пришлите в чат картинки, GIF или стикеры.
Каждое напоминание ученику придёт со случайным мемом из коллекции. Ничего искать в интернете бот не будет:
дети увидят только то, что вы сами добавили.

## Запуск

### 1. Получить токен бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя (например, «Математика с Александрой») и адрес, заканчивающийся на `bot`.
3. BotFather пришлёт токен вида `123456789:AA...`. **Никому его не показывайте**: с ним можно управлять ботом.

Там же можно сделать бота красивым: `/setuserpic` — аватарка (готовая лежит в `assets/avatar.png`),
`/setname` — имя. Описание бота и команды он заполнит сам при первом запуске.

### 2. Узнать свой Telegram ID
Напишите [@userinfobot](https://t.me/userinfobot) — он ответит числом. Это ID администратора:
на него будут приходить обращения в поддержку.

### 3. Установить и запустить
Нужен Python 3.11 или новее ([python.org](https://www.python.org/downloads/)).

```bash
cd bot
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте файл `.env.example` в `.env` и заполните:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_ID
```

Запуск:

```bash
python run.py
```

Откройте своего бота в Telegram и нажмите «Начать».

> Бот работает, пока запущена программа. Чтобы он работал круглосуточно, его нужно разместить
> на сервере (VPS), см. ниже.

### Круглосуточная работа на сервере
Подойдёт самый простой VPS с Ubuntu (Timeweb Cloud, Selectel, Beget и т.п., от ~200 ₽/мес).
Пошагово для новичка: [ЗАПУСК.md](ЗАПУСК.md). Коротко, одна команда на сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/ЛОГИН/РЕПОЗИТОРИЙ/main/deploy/install.sh | sudo bash -s ЛОГИН/РЕПОЗИТОРИЙ
```

Скрипт ставит Docker, скачивает бота в `/opt/tutor-bot`, спрашивает токен и ID и запускает бота
(он сам перезапускается после сбоев и перезагрузки сервера).
Обновить: `cd /opt/tutor-bot && git pull && docker compose up -d --build`.

Вариант без Docker — служба systemd, пример в `deploy/tutor-bot.service`.

База данных — один файл `data/bot.sqlite3`. Для резервной копии достаточно скопировать его.

### Открыть в VS Code
«File → Open Folder» → папка `bot`. VS Code предложит установить расширение Python — согласитесь.
Запускать можно из встроенного терминала (`Terminal → New Terminal`) той же командой `python run.py`.

## Оплата подписки

Если бот нужен только вам (а не другим репетиторам), впишите в `.env` строку `SUBSCRIPTION=off`:
кнопки подписки пропадут, все функции станут бесплатными.

Пока `PAYMENT_PROVIDER_TOKEN` пустой, кнопка «Оплатите подписку» предлагает написать в поддержку,
а администратор продлевает доступ командой:

```
/grant СЕКРЕТ_ВХОДА_УЧИТЕЛЯ 30
```

Чтобы принимать оплату картой прямо в Telegram: @BotFather → ваш бот → Payments → выберите провайдера
(например, ЮKassa), получите токен и впишите его в `PAYMENT_PROVIDER_TOKEN`. Платёж продлевает подписку на `SUB_DAYS` дней.
За 2 дня до окончания бот сам присылает напоминание с кнопкой оплаты (полноценное автосписание с карты
требует отдельного договора с платёжным сервисом).

## Промокоды для друзей

Ученики и родители никогда не платят: подписка нужна только репетиторам, которые пользуются ботом.
Владелец бота (тот, чей ID указан в `ADMIN_IDS`) тоже пользуется им бесплатно.

Промокод даёт репетитору бесплатные дни (30, 90, 180, 365) или бесплатный доступ навсегда.
Создать: кнопка «🛠 Админ-панель» → «🎁 Промокоды» → «➕ Новый промокод». Бот пришлёт готовое сообщение
со ссылкой: подруга открывает её, регистрируется, и промокод применяется сам. Ещё промокод можно ввести вручную
в «⭐ Моя подписка» → «🎁 Ввести промокод». Там же в админ-панели видно, сколько раз промокод использован, и его можно выключить.

## Команды администратора
- `/admin` или кнопка «🛠 Админ-панель» — статистика, промокоды, список преподавателей;
- `/grant СЕКРЕТ ДНЕЙ` — продлить подписку вручную;
- чтобы ответить на обращение в поддержку, ответьте (свайп влево) на пересланное сообщение.

## Для разработчика

```
bot/
  main.py          — запуск, подключение роутеров
  config.py        — настройки из .env
  db.py            — SQLite: преподаватели, ученики, занятия, оплаты, мемы
  logic.py         — разбор дат/времени, расчёт расписания и дохода (без Telegram)
  views.py         — тексты расписания
  subscription.py  — пробный период и оплата
  broadcast.py     — фоновые уведомления (раз в минуту)
  handlers/        — common (старт, регистрация), schedule, students, income,
                     account (подписка, секреты, настройки, мемы), support, family, admin
tests/             — тесты: логика и полные сценарии с фейковым Telegram
```

Тесты: `pip install pytest pytest-asyncio && python -m pytest`.

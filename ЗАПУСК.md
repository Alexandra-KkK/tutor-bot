# Как запустить бота

Всего 4 шага. Код уже готов, от вас нужны токен, ID и сервер.

## Шаг 1. Создать бота в Telegram (5 минут)
1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Имя: например «Математика с Александрой». Адрес: любой свободный, заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456789:AAH...`.
   **Никому его не отправляйте, даже мне в чат.** Он понадобится только на шаге 4.
4. Там же: `/setuserpic` → выберите бота → отправьте картинку `assets/avatar.png` (или свою).

## Шаг 2. Узнать свой Telegram ID (1 минута, можно пропустить)
Если пропустить, владельцем станет тот, кто первым зарегистрируется в боте как преподаватель.
Напишите [@userinfobot](https://t.me/userinfobot), он ответит числом (например `123456789`).
По этому ID бот поймёт, что вы владелец: подписка для вас бесплатная навсегда, вам приходят обращения в поддержку
и доступна «🛠 Админ-панель» с промокодами.

## Шаг 3. Арендовать сервер (~200–300 ₽/мес)
Бот должен работать круглосуточно, иначе не будет напоминаний. Подойдёт самый дешёвый VPS с **Ubuntu 22.04 или 24.04**:
Timeweb Cloud, Beget, Selectel, Aeza и т.п. Хватит 1 ядра и 1 ГБ памяти.
После оплаты хостинг покажет IP-адрес и пароль root.

## Шаг 4. Запустить бота на сервере (10 минут)
1. Код должен лежать на GitHub. Создайте репозиторий на [github.com](https://github.com/new)
   и подключите его к этому проекту, я загружу туда код.
   Публичный проще всего: в коде нет токена и паролей, они хранятся только на сервере.
   Приватный тоже можно, но тогда сервер попросит логин и токен GitHub.
2. Подключитесь к серверу. Windows: откройте «Терминал» (PowerShell), macOS: «Терминал», и введите
   ```
   ssh root@IP_СЕРВЕРА
   ```
   (у многих хостингов есть и консоль прямо в браузере).
3. Вставьте одну команду, подставив свой логин GitHub и название репозитория:
   ```
   curl -fsSL https://raw.githubusercontent.com/ЛОГИН/РЕПОЗИТОРИЙ/main/deploy/install.sh | bash -s ЛОГИН/РЕПОЗИТОРИЙ
   ```
4. Скрипт сам установит всё нужное и спросит токен (шаг 1) и ID (шаг 2). Вставьте их.
5. Готово: откройте бота в Telegram и нажмите «Начать» → «Я преподаватель».

## После запуска
- В «⚙️ Настройки» вставьте ссылку на расписание в Google Диске и добавьте мемы.
- В «👥 Ученики» у каждого ученика есть личная ссылка-приглашение: отправьте её ученику и родителям.
- Промокоды для подруг: «🛠 Админ-панель» → «🎁 Промокоды».
- Если бот нужен только вам и подписка не нужна, напишите мне, это одна строка в настройках.

## Попробовать на своём компьютере (необязательно)
Можно проверить бота до покупки сервера, но он работает, только пока компьютер включён и открыто окно бота.
1. Установите [Python](https://www.python.org/downloads/). На Windows при установке отметьте галочку «Add Python to PATH».
2. Распакуйте папку бота. В ней должен быть файл `.env` с токеном (если его нет: скопируйте `.env.example`
   в `.env` и впишите `BOT_TOKEN=` токен от BotFather).
3. Дважды щёлкните `ЗАПУСТИТЬ.bat` (Windows) или `ЗАПУСТИТЬ.command` (Mac).
   Первый запуск занимает минуту: бот сам установит всё нужное.
4. Откройте бота в Telegram, нажмите «Начать» → «Я преподаватель».
   Первый зарегистрированный преподаватель становится владельцем: бесплатно навсегда и с «🛠 Админ-панелью».

Когда бот заработает на сервере, окно на компьютере нужно закрыть, иначе они будут мешать друг другу.

## Сколько стоит
- Сервер: 200–300 ₽/мес.
- Telegram и сам бот: бесплатно.
- Если другие репетиторы будут платить картой (ЮKassa): комиссия ~3,5% и налог самозанятого 4% с каждого платежа.
